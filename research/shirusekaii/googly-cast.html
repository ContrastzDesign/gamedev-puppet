Build notes

How they're built

Everything is built from Three.js primitives in one file, with no models or image textures. These are the starting values for the skill.

ShadingMeshToonMaterial with a 3-step ramp (0.18, 0.55, 1.0), ambient light at 0.45π and one warm sun at 0.55π. The lit side shows the object's true colour; the shadow side is about 23% darker.
Ink outlineAn inverted hull on a smooth-normal copy of each mesh, pushed out in screen space so the line stays 2.6 px per 1080 px of frame at any distance.
Cast shadowsUnlit lime ground with a ShadowMaterial layer in #3d518c at 94%. One sun from high front-left, 2048 shadow map. Characters cast shadows but don't receive them.
Googly eyeAn off-white puck with an outlined rim, a face texture with the grey lower crescent, and a flat pupil half the eye's width. A clear dome only shows at its edge.
PupilSprings toward the look target (stiffness 350, damping 13) and bounces off the rim (0.5). It also feels the eye's own acceleration and a little gravity, and drifts on its own phase. It settles in about 0.4 s.
BodiesSprings for squash, tilt, lean and turn, hops under gravity 22, and a dust puff on every landing. Bodies turn up to 0.45 rad toward whatever they're looking at.
Depth safetyNo two faces share a depth, so nothing flickers at any distance. The eye's face is the puck's own front cap. Decals sit 0.005 off their surface and use polygonOffset. Solid parts sink at least 0.005 into whatever they sit on. Outlined parts like the eyes stand 0.005 proud instead, so their ink rim never crosses a surface. The camera's near plane is 0.3.
Eye placementEye width is about 0.29 × object width, capped by height on wide objects. Eyes sit about a quarter of the way down the front face. On round objects they follow the curve.
Pupil update, as used on this page 
// u: pupil offset in eye space, normalised so the rim is 1
function updateEye(eye, target, dt, t) {
  const e = eye.userData;
  eye.getWorldPosition(wp);
  vel.subVectors(wp, e.prev).divideScalar(dt);
  acc.subVectors(vel, e.prevVel).divideScalar(dt);   // the eye's own acceleration
  e.prev.copy(wp); e.prevVel.copy(vel);
  eye.getWorldQuaternion(q).invert();                // world to eye space
  acc.applyQuaternion(q);
  dir.subVectors(target, wp).applyQuaternion(q).normalize();
  grav.set(0, -1, 0).applyQuaternion(q);
  let tx = dir.x * 1.25 + 0.07 * Math.sin(t * 0.9 + e.phase);   // own drift
  let ty = dir.y * 1.25 + 0.07 * Math.sin(t * 1.3 + e.phase * 1.7);
  const inv = 0.35 / e.travel;                       // inertia
  e.v.x += (350 * (tx - e.u.x) - 13 * e.v.x - acc.x * inv + grav.x * 50) * dt;
  e.v.y += (350 * (ty - e.u.y) - 13 * e.v.y - acc.y * inv + grav.y * 50) * dt;
  e.u.addScaledVector(e.v, dt);
  const r = e.u.length();
  if (r > 1) {                                      // hit the rim: bounce
    const n = e.u.divideScalar(r);
    const vr = e.v.dot(n);
    if (vr > 0) e.v.addScaledVector(n, -1.5 * vr);
  }
  e.pupil.position.set(e.u.x * e.travel, e.u.y * e.travel, e.pupil.position.z);
}
